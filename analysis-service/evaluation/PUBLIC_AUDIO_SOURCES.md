# 공개 한국어 음성 후보 검토

검토일: 2026-08-07

## Mozilla Common Voice Korean

- 출처: https://commonvoice.mozilla.org/en/datasets
- 라이선스: CC0 1.0
- 사용 조건: Mozilla Data Collective 약관은 내려받은 데이터셋 일부를 외부에 게시하거나 미러링하지 말 것을 요청한다.
- 결정: 실제 사람 음성 검증 후보로 사용할 수 있으나, 음원은 각 개발자가 공식 경로에서 내려받고 이 저장소에는 커밋하지 않는다. 샘플 식별자와 사람 평가 결과만 추적한다.

## OpenSLR SLR40 Zeroth-Korean

- 출처: https://openslr.org/40/
- 라이선스: CC BY 4.0
- 결정: 출처 표시를 유지하는 조건으로 실제 사람 음성 후보에 포함할 수 있다. 필요한 최소 샘플만 로컬에서 사용하고 저장소에는 원본 음성을 커밋하지 않는다.

## OpenSLR SLR58 Pansori-TEDxKR

- 출처: https://openslr.org/58/
- 라이선스: CC BY-NC-ND 4.0
- 결정: 비영리 및 변경 금지 조건이 제품 개발 과정의 재사용·가공 범위와 충돌할 수 있으므로 기본 검증 데이터 후보에서 제외한다.

## 현재 baseline의 범위

현재 저장된 여섯 샘플은 직접 작성한 발표문과 로컬 TTS를 사용한다. TTS 결과는 파이프라인 동작 확인에만 사용하고 발음 정확도 비교에서는 제외한다. 발음 MAE와 상관계수는 적법하게 사용할 수 있는 실제 사람 음성과 사람 평가 점수가 추가된 뒤 계산한다.
